## 🛠️ Saqr Labs forks — coming next

**Naming rule: every fork gets a brand-new invented name of our own —
all names change, none keeps the upstream project's name.**
The upstream is credited in the README and its LICENSE stays untouched;
the new name is our brand, not a claim of authorship of the original code.

Each one is a **real fork** (upstream credit + original license kept), with a
**real improvement**: a clean English UI, a one-click Windows GUI, or a new feature.

| New name | Based on (upstream) | The improvement | Why first |
|---|---|---|---|
| **QariMark** | `microsoft/markitdown` (~198k ★, MIT) | Drag-and-drop Windows GUI: any file → Markdown, live preview, batch conversion | Small effort, giant upstream name |
| **Fakkak** | `bee-san/Ciphey` (~21k ★, MIT) | One big "Decode" button, plain-English guide + automatic plaintext detection | Directly on-topic: decryption |
| **SaqrLocal** | `ggml-org/llama.cpp` (~136k ★, MIT) | One-click Windows launcher (Start/Stop, no CMD) for llama-server — the same engine Strong30 runs on | Ties this profile to my real work |
| **Basama** | `VirusTotal/yara` (~10k ★, BSD-3) | Clearly documented rule library + dead-simple Windows scanner GUI | Rule pack + GUI are genuinely mine |
| **Nabdh** | `projectdiscovery/nuclei` (~33k ★, MIT) | Clearly documented scan templates + simple Windows runner | Templates are real, publishable work |
| **Mufakkik** | `NationalSecurityAgency/ghidra` (~101k ★, Apache-2.0) | Extension pack: beginner tutorial scripts, starter presets, one-click Windows installer | The big-name reverse-engineering piece |

*Every fork keeps the original LICENSE and copyright files untouched, and its
README says clearly: "Based on [original] by [owner], licensed under
[license]. Not affiliated with or endorsed by the original project."*
*Security tools here are defensive and educational — my own systems,
authorized testing, learning.*

## 🧭 How I work

- **Strength over speed** — I don't cap verification depth to save time. Excellent or it doesn't ship.
- **Test before announcing** — nothing is "done" until it passes the real path, end to end.
- **One click** — my tools are one package, one Start button, one Stop button. No console windows, no CMD for the user.
- **Show the shape first** — for design work, I review a mockup before anything is built.
- **My safety layer stays mine** — a separate protection layer on top of the model, never trained into it.
